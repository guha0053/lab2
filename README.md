Lab 2 – Feedback Form

Target:
Grade 3

Project Description

This project is a responsive webpage with a feedback form built with HTML, CSS and JavaScript. It allows users to submit feedback through a form with input validation and clear error messages and form input fields.

Features

Full name validation, including support for international characters.

Email address validation.

Required topic selection.

Comment field with a live character counter and a minimum of 15 characters.

Optional website field with URL validation.

Clear error messages displayed next to the relevant fields.

Visual feedback for focused, invalid, and valid fields.

Success message displayed after a successful submission.

Form fields and validation states reset after submission.

Clear button to restore the initial form state.

Responsive layout for different screen sizes.

Accessible form labels and status messages.
